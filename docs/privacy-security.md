# Privacy and security review checklist

This project makes no claim of compliance. Before collecting real personal data, have qualified local counsel and privacy/security reviewers assess Uganda's Data Protection and Privacy Act, 2019 and applicable regulations, as well as the jurisdictions relevant to actual donors and beneficiaries.

Define purpose and lawful basis, plain-language notices, consent records, minimum fields, access/correction/deletion request handling, retention schedules, processor agreements, incident handling and data-subject contact. Keep health/help/child information out of public pages, analytics, URLs, logs and ordinary email. Restrict and audit access. Add secure file validation/moderation, persistent secure sessions, CSRF, verification/reset workflows, encryption/key management, rate limits on sensitive endpoints and object-level access controls. No tracking analytics are installed.

Accessibility target is WCAG 2.2 AA, but no automated or manual audit has been run. Confirm keyboard/dialog behavior, contrast, zoom/reflow, screen-reader output and mobile safe-area behavior with independent review.
