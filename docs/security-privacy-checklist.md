# Security and privacy checklist

- [ ] Persistent session store and CSRF token validation
- [ ] Email verification, reset and recovery with single-use expiring tokens
- [ ] Secure staff invitation and role administration
- [ ] Field-level sensitive data review, encryption, retention, correction/deletion flows
- [ ] Rate limits on all public sensitive submissions and authentication operations
- [ ] File type/content/dimension validation, generated names, malware review and moderation
- [ ] Audit coverage for approvals, exports, financial edits, role changes and sensitive reads
- [ ] Payment provider official verification, idempotency and reconciliation
- [ ] Privacy/legal review for Uganda and relevant jurisdictions
- [ ] Safeguarding and accessibility review
