# Deployment checklist

- [ ] Authorized organization facts, logo, contact routes, policies and safeguarding content approved.
- [ ] Independent testing and security review completed; legal/privacy review completed.
- [ ] Persistent storage, encrypted backups and restore drill confirmed.
- [ ] Persistent session store, CSRF, verification/reset, invitations and access controls completed.
- [ ] TLS, secure cookies, proxy trust and secret manager configured.
- [ ] SMTP configured and transactional flows reviewed.
- [ ] Payment provider jurisdiction, merchant, currencies, webhooks, sandbox reconciliation and refund behavior reviewed.
- [ ] Accessibility, safeguarding, retention and incident response reviewed.
- [ ] Monitoring, log rotation, patching, rollback and maintenance response assigned.
